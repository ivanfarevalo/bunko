# Changelog

## Unreleased

- **Reports.** `bunko report` makes HTML reports in a consistent theme and
  folder layout, and checks them. `/report`, installed with `bunko skill
  install`, lets Claude Code and Codex write up your work that way and hand
  you the link. Kinds of report, workspace layouts, and themes are settings
  you change with commands, or by asking your agent, per user or per project.
  The built-in house theme has a side table of contents, light and dark modes,
  an expandable embedded-player frame, and a collapsed "How this was made"
  panel. See docs/reports.md.
- **`bunko link PATH`** prints the URL that opens a file or folder in the
  running Bunko that serves it, with `--line N` for text files. `bunko servers`
  lists the running servers. Scripts and AI agents can now end with a link.
- **`--public-url`** sets the address `bunko link` uses, for servers behind a
  proxy. Under `--allow-user`, Bunko uses your Tailscale HTTPS name.

## 0.3.0

- **Renamed from shelf to Bunko.** The command and package are `bunko`, its
  files live in `~/.config/bunko` and `~/.cache/bunko`, and its URLs sit under
  `/__bunko/`.
- **Recent files, favorites, and tags** at the top of the sidebar. Star and tag
  buttons sit in the top bar, and each tag gets its own section. Sections
  collapse, and the heading of the section you're in sticks to the top as the
  sidebar scrolls. Stored on the server per served folder, and per person under
  `--allow-user`.
- **Nicknames for favorites,** shown in place of the file name with the full
  path beside it. Set them when starring, from the star again, or with ✎ in the
  sidebar.
- **Word and Excel files.** `.docx` opens as a page with headings, lists,
  tables, images, footnotes, and an outline. `.xlsx` opens in the table viewer
  with a tab per sheet and Excel's row numbers. Both are converted on the server
  with the standard library. Older `.doc` and `.xls` files explain why they
  don't open.
- **Listens on 127.0.0.1 by default,** so a new server is private to its machine.
  Reaching it from elsewhere takes `-b`, an SSH tunnel, or Tailscale Serve.
- A new color palette, in light and dark.
- DOMPurify updated to 3.5.0, for its sanitizer security fixes.
- Paging through files with the arrow keys doesn't count toward Recent.
- Dropped browser connections no longer print tracebacks.
- Bunko's first write endpoint (`/__bunko/api/places`), protected against
  cross-site requests. The served folder is still never written.

## 0.2.0

- **Access control:**
  - Tailscale identity (`--allow-user`, behind `tailscale serve`).
  - Access tokens (`--token`, `bunko token`) with a sign-in page, an
    `HttpOnly` cookie, rotation without restart, and Bearer support for scripts.
  - A warning at startup when the server is open to the network.
- **Search inside files**, using ripgrep or a Python fallback. Results open the
  file at the matching line, highlighted.
- **Video review tools:** frame stepping, frame numbers and frame rate from
  ffprobe, speed control, keyboard shortcuts, and links to an exact time
  (`?t=`).
- **Thumbnails** for large images and video posters, generated by ffmpeg and
  cached.
- **JSONL as tables,** with a switch to show them as text.
- **Outline beside Markdown,** optional and remembered.
- **Settings panel:** theme, viewer options, keyboard shortcuts, and who you're
  signed in as.
- **`bunko service`:** install, inspect, and remove systemd user services.
- **Links into files:** `?line=` and `?q=`.
- Fix: natural sort now compares names without their extension first, so
  `clip.mp4` sorts before `clip2.webm`.
- The command line moved to `bunko.cli`.

## 0.1.0

- First version: a browser UI for a folder, with Markdown, HTML,
  images, video, CSV and TSV tables, PDF, code, and text viewers, name search,
  live reload, dotfile protection, and range requests.
