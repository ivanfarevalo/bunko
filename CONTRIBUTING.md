# Contributing

Thanks for helping. [docs/development.md](docs/development.md) covers the code
layout, how to run the tests, and the rules that keep shelf easy to run:
standard library only, no front-end build step, and read-only.

- **Bugs:** open an issue with the steps to reproduce, your OS, your Python
  version, and your browser.
- **Features:** open an issue first to talk it over.
- **Security problems:** report privately. See [SECURITY.md](SECURITY.md).
