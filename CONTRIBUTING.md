# Contributing

Thanks for helping. [docs/development.md](docs/development.md) covers setting
up with uv, the linters and pre-commit hooks, the code layout, the tests, and
the practices the code follows: standard library only, no front-end build
step, and never writing to the served folder.

- **Bugs:** open an issue with the steps to reproduce, your OS, your Python
  version, and your browser.
- **Features:** open an issue first to talk it over.
- **Security problems:** report privately. See [SECURITY.md](SECURITY.md).
